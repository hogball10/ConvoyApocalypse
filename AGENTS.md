# Roblox agent workspace (robld)

After install, load `.grok/skills/robld/SKILL.md` (or `.claude/skills/robld/SKILL.md`) into this session now.
Never ask the user to run robld commands or flags unless they asked; you run them.
Run `robld` from this folder until stdout contains `READY:`.
If the skill is missing, run `robld --install`. If a new version is available, run `robld --update`.
Skill: `.claude/skills/robld/SKILL.md` (also installed for Grok, Codex, Cursor, and `.agents`).
Full how-to: https://robld.com/
